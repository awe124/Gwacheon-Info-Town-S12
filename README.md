# 과천지식정보타운 S12블록 행복주택 랜딩페이지

기존과 동일하게 GitHub Pages에서 바로 사용할 수 있는 정적 페이지입니다. 빌드나 패키지 설치가 필요하지 않습니다.

## 파일 구성

- index.html: 페이지 제목, 설명, 상단 메뉴, 청약플러스 버튼, 상단 이동 버튼
- style.css: PC·모바일 화면 스타일
- assets/landing.jpg: 제공된 원본 이미지 (723 × 2,048px)

## 기존 GitHub 저장소에 적용

1. ZIP 파일을 압축 해제합니다.
2. 기존 저장소 루트의 index.html과 style.css를 같은 이름의 새 파일로 교체합니다.
3. assets 폴더 안의 landing.jpg도 교체합니다. 기존 GitHub의 assets 폴더를 연 다음 Add file → Upload files로 landing.jpg를 업로드하면 됩니다.
4. README.md도 필요하면 함께 교체합니다.
5. Commit changes로 저장하고 배포가 완료되면 기존 GitHub Pages 주소에서 확인합니다. 이전 이미지가 남으면 Ctrl+F5로 새로고침합니다.

새 저장소라면 index.html, style.css, assets 폴더, README.md가 저장소 최상단에 위치하도록 업로드하고 Settings → Pages에서 main 브랜치의 /(root)를 선택합니다. ZIP 파일 자체를 업로드하지 않습니다.

## 연결 및 이미지 안내

- LH 홈페이지: https://www.lh.or.kr
- LH 청약플러스: https://apply.lh.or.kr
- 별도의 전화 연결 버튼은 없습니다. 원본 이미지에 포함된 콜센터 번호는 그대로 표시됩니다.
- 공급 일정과 신청 자격은 별도로 추가하지 않았습니다. 청약플러스 버튼은 서비스 메인 화면으로 연결됩니다.
- JPG 두 파일의 내용이 같아 한 장만 사용했습니다. 이미지 재압축이나 문구 변경 없이 원본을 복사했습니다.
- 작은 글씨의 모바일 가독성은 제공된 이미지 해상도의 영향을 받습니다. 화면 확대가 가능하도록 확대 제한은 설정하지 않았습니다.
- 공유 미리보기 제목·설명·이미지 경로를 설정했습니다. og:image는 상대 경로이며, 운영 주소가 확정되면 해당 주소의 /assets/landing.jpg 전체 URL로 바꾸는 것을 권장합니다.

## 로컬 확인

index.html을 브라우저에서 열면 이미지와 스타일을 확인할 수 있습니다. 외부 서비스 링크는 인터넷 연결이 필요합니다.
